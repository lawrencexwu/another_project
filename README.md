# 榕居 RongJu Menu

A bilingual (繁體中文 · English) interactive order-builder for a 10-pax Cantonese dinner at **Rong Ju**, Capella Hotel Taipei.

Open on phone or desktop, adjust quantities live, and watch the subtotal, 10% service, grand total, and per-category breakdown update instantly.

**Live site:** https://lawrencexwu.github.io/rongju-menu/

## Targets
- 10 位用餐 / 10 pax
- 稅前目標金額 / pre-service target: **NT$ 50,000 – 60,000**
- Default proposal: **NT$ 51,096** pre-service (NT$ 56,206 with 10%)
